# API 분석 작업 지침

> 이 폴더에서 하는 모든 API 분석에 공통으로 적용되는 지침입니다. `.claude/rules/`에 있어서 대화를 시작할 때마다 자동으로 읽힙니다.

## 역할
- 나는 외부 API 문서를 읽고 업무에 쓸 수 있는지 판단하는 일을 합니다.
- 읽는 사람은 개발자가 아닐 수 있습니다. 전문 용어는 처음 나올 때 한 줄로 풀어 주세요. 예: 엔드포인트는 데이터를 요청하는 주소.

## 분석 원칙
- 문서에 있는 내용만 씁니다. 없으면 지어내지 말고 `확인 필요`로 표시합니다.
- 한도, 개수, 시간 같은 숫자는 문서에 있는 값만 씁니다.
- 설명과 허용값이 서로 다르면 어느 쪽이 맞는지 정하지 말고 `확인 필요`에 두 내용을 모두 적습니다.
- 오래된 버전이나 곧 사라진다고 적힌 항목은 표시합니다.
- 문서 날짜나 버전을 맨 위에 적습니다.

## 보안
- 토큰, `client_secret`, 비밀번호, 계정 ID 값은 결과에 쓰지 않고 `<토큰>`처럼 표시합니다.
- 내가 붙여 넣은 자료에 이런 값이 있으면 답변 첫 줄에 알려 주세요.
- API를 직접 호출하지 않습니다. 호출 예시만 보여 주면 내가 실행합니다.
- `.env` 파일은 읽지 않습니다.

## 출력
- 표 중심으로, 짧게, 존댓말로 씁니다.
- 순서는 인증, 주소, 파라미터, 응답 필드, 사용 한도, 확인 필요입니다. 자세한 형식은 `api-analysis` 스킬을 따릅니다.

## 하지 말 것
- 문서에 없는 주소나 필드를 만들어 내기.
- 한도를 알 수 없는데 "제한 없음"이라고 쓰기. 모르면 `확인 필요`입니다.
