# 1장. Claude, 어떤 도구를 쓸까?

> [!info] 확인한 날짜
> 2026-10-15 · 공식 문서: <https://code.claude.com/docs/en/overview>

## 3줄 요약
> [!summary] 먼저 기억할 것
> - 채팅은 물어보고 답을 듣는 도구입니다. Claude Code는 내 컴퓨터의 파일을 직접 열어서 일합니다.
> - Claude Code는 내 컴퓨터에서 실행할 수도 있고(로컬), Anthropic의 서버에서 실행할 수도 있습니다(클라우드).
> - 처음엔 채팅과 로컬 Claude Code만 알면 됩니다.

## 핵심 개념

### 1) 채팅과 Claude Code
| | 채팅 (claude.ai) | Claude Code |
|---|---|---|
| 하는 일 | 질문에 답하고 글을 써 줌 | 파일을 읽고, 만들고, 고침 |
| 내 파일 | 붙여넣거나 올려야 봄 | 작업 폴더 안은 직접 봄 |
| 잘하는 일 | 아이디어, 요약, 문장 다듬기 | 여러 파일 정리, 반복 작업 |

> [!note] 용어: 작업 폴더
> Claude가 들어가도 된다고 내가 정해 준 폴더입니다. 다른 폴더는 열지 않습니다.

### 2) 로컬과 클라우드
| | 로컬 | 클라우드 |
|---|---|---|
| 실행되는 곳 | 내 컴퓨터 | Anthropic의 컴퓨터(서버) |
| 파일 | 내 컴퓨터 파일을 직접 다룸 | 온라인(GitHub)에 올려 둔 git 저장소의 파일로 일함 |
| 컴퓨터를 끄면 | 멈춤 | 계속 실행됨 |

> [!note] 용어: GitHub
> 클라우드는 파일을 GitHub에서 가져옵니다. GitHub는 파일을 온라인에 보관하는 서비스로, 주로 개발 팀이 씁니다.

> [!tip] 처음이라면
> 문서 작업이 많다면 로컬로 시작하면 됩니다.

## 따라 하기
내 일이 아래 표의 어느 줄과 가장 비슷한지 찾아 보세요.

1. 표를 읽고 내 상황과 가까운 줄을 고릅니다.
2. 추천 칸의 도구로 일을 시작합니다.

| 상황 | 추천 | 이유 |
|---|---|---|
| 회의 내용을 3줄로 요약하고 싶다 | 채팅 | 붙여넣기만 하면 끝 |
| 메일 문장을 부드럽게 다듬고 싶다 | 채팅 | 짧은 글 작업 |
| 아이디어를 같이 정리하고 싶다 | 채팅 | 대화가 중심 |
| 폴더의 보고서 10개를 같은 양식으로 고치고 싶다 | Claude Code (로컬) | 여러 파일을 직접 수정 |
| 흩어진 메모 파일을 한 문서로 합치고 싶다 | Claude Code (로컬) | 폴더 안 파일을 직접 읽음 |
| 매번 같은 규칙으로 문서를 만들고 싶다 | Claude Code (로컬) + 지침 | 규칙을 파일로 저장 |
| 오래 걸리는 작업을 맡기고 PC를 끄고 싶다 | Claude Code (클라우드) | 서버에서 계속 실행 |
| GitHub에 올리지 않은 내 PC 파일이 필요하다 | 로컬 | 클라우드는 GitHub에 올린 파일만 봄 |

> [!tip] 클라우드는 나중에
> 클라우드는 필요해질 때 보면 됩니다.
