# Claude 사용 가이드

> [!info] 확인한 날짜
> 2026-10-15 · 공식 문서: <https://code.claude.com/docs>

비개발자를 포함한 팀원이 Claude를 이해하고, 혼자 설치해 시작하고, 안전하게 쓰고, 업무에 적용하도록 돕는 가이드입니다. Windows와 Claude 데스크톱 앱 기준이며, 1장부터 순서대로 읽으세요.

| 장 | 내용 | 읽고 나면 |
|---|---|---|
| [1장](01-개념.md) | 채팅 vs Claude Code, 로컬 vs 클라우드 | 상황에 맞는 도구를 고릅니다 |
| [2장](02-설치와-시작.md) | 설치와 첫 대화 | 혼자 설치해 시작합니다 |
| [3장](03-안전하게-쓰기.md) | 안전하게 쓰기 | 입력해선 안 되는 것과 권한 대응을 압니다 |
| [4장](04-지침.md) | 지침(CLAUDE.md) | 항상 지킬 규칙을 Claude에게 알려 줍니다 |
| [5장](05-스킬.md) | 스킬 | 반복 작업을 절차로 저장하고, API 분석을 시켜 봅니다 |

> [!tip] 예제 파일
> 이 가이드의 상위 폴더에 있는 `.claude/`(규칙, 스킬, 설정)가 3~5장에서 설명하는 차단 규칙, 지침, 스킬의 실제 모습입니다. 상위 폴더의 [CLAUDE.md](../CLAUDE.md)는 가이드를 쓰는 작업 지침이라 따라 할 필요는 없습니다.
